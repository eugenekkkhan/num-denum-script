# Скрипт для еженедельного изменения числителя/знаменателя в чатах Telegram
### Предисловие:
Я как среднестатистический студент был посвящен своими кураторами со старших курсов в их лайфхаки, связанные с отслеживанием того, какой сейчас период: знаменатель или числитель. Самым простым способом сделать это все на виду было изменять название группового чата раз в неделю добавляя че-то типа "[Ч]" или "[З]" в зависимости от периода. У нас для этого был отдельный человек, который сам порой забывал менять название чата. Поэтому я решил разработать сей скрипт...
### Суть скрипта:
Данный скрипт на питоне позволяет при помощи библиотеки Telethon выполнять изменение названий массива чатов каждую неделю
### Настройка:
1. Создайте виртуальное окружение Python (если Python отсутствует, то [скачайте...](https://www.python.org/downloads/)): `python3 -m venv venv`

2. Зайдите в виртуальное окружение: `source venv/bin/activate`

3. Установите зависимости `pip install -r requirements.txt`

4. Запустите сам скрипт: `python3 main.py`

5. Настройте скрипт под себя
